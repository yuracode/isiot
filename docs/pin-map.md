# 今回使うピン一覧

| 部品 | 端子 | Pico GPIO | 物理ピン |
|---|---|---|---|
| 人感センサー SB412A | VCC / GND / OUT | 3V3(OUT) / GND / GP15 | 36 / 38 / 20 |
| 信号機 赤 | | GP2 | 4 |
| 信号機 黄 | | GP3 | 5 |
| 信号機 緑 | | GP4 | 6 |
| 信号機 GND | | GND | 3 |
| タクトスイッチ | 片側 / もう片側 | GP5 / GND | 7 / 8 |
| 超音波 HC-SR04 | VCC / GND | VBUS(5V) / GND | 40 / 38 |
| 超音波 Trig | | GP10 | 14 |
| 超音波 Echo | 分圧回路経由 | GP11 | 15 |

> ⚠️ **「GP番号」と「物理ピン番号」は別物!**
> 例:**物理3番は GND** であって、GP3 ではないよ。
> 配布したピン配置図で、GP番号と物理ピン番号の両方を見比べよう。

- 本体LED は **GP25**(外に出ているピンではない)。Pico W の場合は `Pin("LED", Pin.OUT)`。
- 物理38番の GND は人感センサーと超音波センサーで共有するよ。両方つなぐときはブレッドボードの「−」の列で GND をまとめよう。
