# うまく動かないときは

まずは **落ち着いて、上から順に** チェックしよう。配線を直すときは **USB を抜いてから** ね。

## Thonny が Pico を認識しない

- [ ] Thonny の右下のインタプリタが **「MicroPython (Raspberry Pi Pico)」** になっている?
- [ ] USB ケーブルが **充電専用** ではない?(データ通信できるケーブルが必要)
- [ ] USB ケーブルを一度抜いて、さし直した?
- [ ] 停止ボタン(■)を押してから、もう一度 実行(▶)してみた?

## LED が光らない

- [ ] **GP番号と物理ピン番号** を取り違えていない?(例:GP3 は物理5番。物理3番は GND)→ [ピン一覧](pin-map.md)
- [ ] 信号機モジュールの **GND** はつながっている?
- [ ] 単体の LED なら、**向き** は合っている?(足の長いほうが +、短いほうが −)
- [ ] 単体の LED に **抵抗** は入っている?
- [ ] 配線チェック(02 の最初の部分)で、表示された色と光った色は合っている?

## ボタンが反応しない/逆になる

- [ ] `Pin.PULL_UP` を書いた?
- [ ] プルアップでは **押すと 0** だよ。`if button.value() == 0:` になっている?
- [ ] タクトスイッチの足の向きは合っている?(**対角線** の足を使うと確実)
- [ ] ポーリング版では、**黄・赤の最中(sleep 中)は反応しない** よ。それは正常な動きだよ → [04 割り込み版](../04-button-irq/README.md)

## 人感センサーが反応しっぱなし/反応しない

- [ ] 電源を入れてから **ウォームアップ(30秒くらい)** 待った?
- [ ] 一度検知すると、しばらく HIGH が続く(**ホールド時間**)よ。少し離れて待ってみよう。
- [ ] センサー基板の印字で **VCC / OUT / GND の並び** を確かめた?
- [ ] 人感センサーは「熱の **変化**」に反応する。じっとしていると反応しないこともあるよ。

## 超音波センサーが「測定不可」ばかり

- [ ] VCC は **VBUS(物理40番、5V)** につながっている?(3V3 ではうまく動かないことがある)
- [ ] Trig は GP10(物理14番)、Echo は GP11(物理15番)?逆になっていない?
- [ ] **分圧回路** の配線は合っている?(Echo 側が 1kΩ、GND 側が 2kΩ)
- [ ] 対象が **近すぎない?**(2cm より近いと測れない)
- [ ] 対象が **斜め** になっていない?やわらかい物(布・スポンジ)ではない?
- [ ] 測る対象までの距離が 4m より遠くない?

## それでもダメなときは

- エラーメッセージ(Shell に出る赤い文字)を読んでみよう。何行目でエラーが出ているかが書いてあるよ。
- 元のプログラム(各ステップの `.py`)をもう一度コピーして動かしてみよう。動けば、自分の変更した部分に原因があるよ。
- まわりの友だちや先生に聞いてみよう!
