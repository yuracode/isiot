# 電気の基本まとめ

電子回路がはじめての人のために、このリポジトリで使う電気の話をまとめたよ。

## 電圧・電流・抵抗を「水」でたとえる

| 電気 | 水でたとえると | 単位 |
|---|---|---|
| **電圧**(V) | 水の **高さ**(高いところから低いところへ流れる力) | V(ボルト) |
| **電流**(I) | 流れる水の **量** | A(アンペア)、mA(ミリアンペア)= 0.001A |
| **抵抗**(R) | 水路の **細さ**(細いほど流れにくい) | Ω(オーム)、kΩ(キロオーム)= 1000Ω |

- Pico の GPIO は **3.3V**(HIGH = 1)か **0V**(LOW = 0)。
- **GND** は 0V。電気の「帰り道」だよ。

## オームの法則

**電圧 V = 電流 I × 抵抗 R**

形を変えると:
- I = V ÷ R(電流を求める)
- R = V ÷ I(抵抗を求める)

### 例:LED の電流制限抵抗([02](../02-traffic-light/README.md))

LED は光るときに約 2.0V を使う(順方向電圧 Vf)。

| 段階 | 内容 |
|---|---|
| 式 | I =(電源の電圧 − LED の電圧)÷ R |
| 数値を入れる | (3.3V − 2.0V)÷ 220Ω = 1.3V ÷ 220Ω |
| 答え | ≒ 0.006A = **6mA** |

単体の LED には **220Ω 程度** の抵抗を必ず入れよう。

## プルアップとプルダウン

何もつながっていない入力ピンは、HIGH か LOW か決まらず **ふらふら(フローティング)** する。
抵抗を通して決まった電圧に「引っ張って」おくのがプルアップ/プルダウンだよ。

| | プルアップ | プルダウン |
|---|---|---|
| 引っ張る先 | 3.3V | GND |
| 何もないときの値 | **1** | **0** |
| MicroPython | `Pin.PULL_UP` | `Pin.PULL_DOWN` |
| このリポジトリでの使い道 | ボタン(押すと **0**)→ [03](../03-button-polling/README.md) | 人感センサー(検知すると 1)→ [05](../05-pir-sensor/README.md) |

```
プルアップ             プルダウン
 3.3V                   3.3V(センサー出力など)
  │                      │
 [抵抗]                  ┴ スイッチ
  ├── 入力ピン           ├── 入力ピン
  ┴ スイッチ            [抵抗]
  │                      │
 GND                    GND
```

Pico にはプルアップ・プルダウン用の抵抗が **内部にある** ので、外付けしなくていいよ。

## 分圧

抵抗を直列に2つつなぐと、電圧は **抵抗の大きさに比例して分かれる**。

**出力電圧 = 入力電圧 × R2 ÷(R1 + R2)**

### 例:超音波センサーの Echo([06](../06-ultrasonic/README.md))

| 段階 | 内容 |
|---|---|
| 式 | 出力電圧 = 入力電圧 × R2 ÷(R1 + R2) |
| 数値を入れる | 5V × 2kΩ ÷(1kΩ + 2kΩ)= 5 × 2/3 |
| 答え | ≒ **3.3V** |

```
Echo ──[1kΩ]──┬── GP11
              │
            [2kΩ]
              │
             GND
```

たとえ:水の流れを2つの坂に分けると、途中の高さは坂の長さで決まる。

> ⚠️ Pico の入力は 3.3V まで。**5V を GPIO に直接入れない!**
