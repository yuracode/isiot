# Raspberry Pi Pico でセンサーを動かそう

〜信号機・人感センサー・超音波センサー〜

Raspberry Pi Pico(ラズベリーパイ ピコ)という小さなコンピュータで、LED を光らせたり、ボタンやセンサーの値を読んだりしてみよう。
このリポジトリは、**上から順番に読んでいけば自分で作業できる** ように作ってあるよ。

## 📚 このリポジトリの使い方

1. 下の目次の **00 から順番に** 進めよう。各フォルダの `README.md` を上から読めば作業できるよ。
2. プログラムは **コピーして Thonny に貼り付けて OK**。まず動かしてみて、それから読み解こう。
3. 各ステップの最後にある **🤔 考えてみよう** と **🚀 改良チャレンジ** で、自分なりに改良してみよう。
   - ヒントと解答例は `<details>`(クリックで開く部分)に隠してあるよ。**まずは自分で考えてから** 開こう。
   - 解答例は「1つの答え」にすぎないよ。別の書き方でも、動けば正解!

## 📌 ピン配置図について

Pico のピン配置図(どのピンが何番か)は、**授業で配布したプリント** を見よう。
手元にないときは公式のピン配置図(PDF)を見てね:
https://datasheets.raspberrypi.com/pico/Pico-R3-A4-Pinout.pdf

## ⚠️ 安全上の注意

- **配線を変えるときは、必ず USB ケーブルを抜いてから** にしよう。
- **5V を GPIO(GP〇〇のピン)に直接入れない。** Pico の入力は 3.3V までだよ(→ [06](06-ultrasonic/README.md) で分圧回路を使う理由)。
- LED を単体で使うときは、必ず **電流制限抵抗(220Ω程度)** を入れよう。
- 部品が熱くなったり、焦げたにおいがしたら、すぐに USB を抜いて先生に知らせよう。
