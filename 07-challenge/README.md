# 07. チャレンジ課題

## 🎯 このステップのゴール

- これまでのステップの部品とプログラムを **組み合わせて** 新しい動きを作れる
- 自分で考えて、試して、直す(デバッグする)ことができる

## 📝 進め方

1. 課題を選んで、「使う部品」「使うステップ」を確認しよう。
2. 使うステップの **ピン設定と関数をコピー** してきて、組み合わせよう。
3. 自分のコードは **`my_answer1.py` などの名前で保存** しておこう(あとで見返せるし、解答例とくらべられるよ)。
4. 行きづまったら **ヒント** を開こう。解答例は最後に!
5. 解答例は1つの例にすぎないよ。**別の書き方でも、動けば正解!**

全部の部品をつなぐときのピン一覧 → [今回使うピン一覧](../docs/pin-map.md)

> 配布したピン配置図で、GP番号と物理ピン番号の両方を確かめよう。
> 配線を変えるときは、必ず USB を抜いてからにしよう。

## 課題3:ボタンを押したら超音波で距離を測り、距離に応じて信号の色を変える

| 使う部品 | 使うステップ |
|---|---|
| 信号機・タクトスイッチ・超音波センサー(+分圧回路) | [02](../02-traffic-light/README.md)・[03](../03-button-polling/README.md)・[06](../06-ultrasonic/README.md) |

例:10cm 未満 → 赤 / 30cm 未満 → 黄 / それ以上 → 緑

<details>
<summary>ヒントを見る</summary>

- 03 のボタンの読み方(チャタリング対策・離すまで待つ)をそのまま使おう。
- 3つ以上に分けるときは `if` / `elif` / `else` が便利だよ(`elif` =「そうでなくて、もし〜なら」)。
- 小さい距離から順番に調べるのがコツ。

</details>

## 課題4(+α):人がいるときだけ、距離に応じて信号の色を変え続ける

| 使う部品 | 使うステップ |
|---|---|
| 信号機・人感センサー・超音波センサー(+分圧回路) | [02](../02-traffic-light/README.md)・[05](../05-pir-sensor/README.md)・[06](../06-ultrasonic/README.md) |

人がいないときは全部消灯(省エネ)、人がいるときは課題3と同じルールで色を変え続けよう。

<details>
<summary>ヒントを見る</summary>

- 人感センサーの GND(物理38番)と超音波の GND(物理38番)が同じピンになるね。ブレッドボードの「−」の列を使って GND をまとめよう。
- 「距離 → 点けるLED」を決める部分を関数にすると、課題3のコードも再利用しやすくなるよ。

</details>
