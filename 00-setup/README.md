## 📖 知っておきたいこと

### Raspberry Pi Pico と GPIO

- Pico は **マイコン**(=小さなコンピュータ)だよ。プログラムを書き込むと、その通りに動いてくれる。
- **GPIO**(ジーピーアイオー)は、Pico が電気を ON/OFF したり、読み取ったりできる「出入口」だよ。
  - **出力(OUT)**:Pico から電気を出す(例:LED を光らせる)
  - **入力(IN)**:外から来た電気を読み取る(例:ボタンが押されたか調べる)
- **3.3V が HIGH(1)、0V が LOW(0)**。プログラムでは 1 と 0 で表すよ。

### GP番号と物理ピン番号は別物!

Pico のピンには、2種類の番号があるよ。

| 番号の種類 | 意味 | 例 |
|---|---|---|
| **GP番号** | プログラムで使う番号 | `Pin(3, Pin.OUT)` の 3 は **GP3** |
| **物理ピン番号** | 基板の端から数えた、ピンの位置の番号(1〜40) | GP3 は **物理5番** |

> ⚠️ たとえば **物理3番は GND** であって、GP3 ではないよ!
> 配布したピン配置図で、GP番号と物理ピン番号の両方を確かめよう。

公式のピン配置図(PDF):https://datasheets.raspberrypi.com/pico/Pico-R3-A4-Pinout.pdf

## 🔌 配線

このステップでは、USB ケーブルで Pico とパソコンをつなぐだけだよ。

> ⚠️ 充電専用の USB ケーブルだと Pico を認識しないよ。データ通信できるケーブルを使おう。

## 💻 Thonny の設定

1. Pico を USB でパソコンにつなぐ。
2. Thonny を起動する。
3. **右下** のインタプリタ表示をクリックして、**「MicroPython (Raspberry Pi Pico)」** を選ぶ。
4. 下の **Shell** に `>>>` が出ればつながっているよ。

試しに、Shell に次のように打って Enter を押してみよう。

```python
print("こんにちは Pico")
```

`こんにちは Pico` と表示されれば成功!

### ボタンの使い方

| ボタン | 意味 |
|---|---|
| ▶ 実行(緑の三角) | エディタに書いたプログラムを Pico で動かす |
| ■ 停止(赤い四角) | 動いているプログラムを止める(`while True` を止めるときに使う) |

- `print()` の結果は **Shell** に表示されるよ。
- プログラムを **Pico に `main.py` という名前で保存** すると、USB 電源を入れただけで自動で動くようになるよ(授業では保存しなくて OK)。
